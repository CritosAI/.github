# CritOS

### Multi-agent governance for your repository.

**Give every agent a domain, a memory and a boundary.**

[Website](https://critos.dev) · [The repository](https://github.com/CritosAI/critos) · [Install](https://github.com/CritosAI/critos#install) · [Guides](https://github.com/CritosAI/critos/tree/main/docs)

</div>

Good agents are built by a good team. **CritOS organises the agents that build your software.**

A coding agent is brilliant for one session. Your project lasts years. CritOS is a development
method for people who build software with AI coding agents, and the tools that keep it honest:
each agent **owns a domain** of the project, keeps the **memory** of that domain in your
repository, and a shared inbox, deterministic checks, a guard and a steward keep the whole team
honest. Plain files, in git. Open source, Apache-2.0. No telemetry.

- **Agents forget. Your repo doesn't.**
- **The memory lives in your repo, not in the model.**
- **Expertise you can read, diff and revert.**

Built for **Claude Code**, on Windows and Linux. Start here: [CritosAI/critos](https://github.com/CritosAI/critos).
